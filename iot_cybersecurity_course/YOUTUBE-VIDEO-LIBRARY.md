## Embedding QA / editorial red flags

- Run title/creator verification again near deployment, inspect exact playback and confirm correct topic, spoken language, captions and current availability.
- Avoid treating a video as fully covering a 4-lesson module. Use original written scaffolding to fill gaps; label `supporting overview` where relevant.
- Link to videos; do not download/rehost media or remove creator identity.
- If creator disables embedding, link externally instead of creating a broken player.
- Do not make the video URL an unverified prerequisite for permanent course progression.
