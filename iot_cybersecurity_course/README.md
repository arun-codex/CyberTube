# IoT Cybersecurity & Ethical Hacking: Zero to Advanced

**Date prepared:** 2026-11-24  |  **Language:** English  |  **Audience:** beginners, junior SOC analysts and ethical IoT security researchers.
**Format:** 30 modules · 120 lessons · self-paced video-first course · Markdown source files · no quizzes.

## Course promise and limits

An end-to-end, cybersecurity-only IoT learning path. The basics are included *only when needed to understand security*: architectures, devices and protocols are taught from a threat, defense and forensic perspective. There is no general Arduino maker-course content.

**Important:** This is a **curated course design**, not an existing single end-to-end YouTube playlist. Each module includes working-format YouTube URLs identified in public search/publisher material; playback, current video availability, country limits, captions, embed permissions and full topical coverage have **not** been confirmed by opening the YouTube player. Some videos are reused where their scope supports multiple modules. Course length is learning-time estimate, not video runtime.

## Learning outcomes

On completion, a learner should be able to (1) inventory an IoT attack surface; (2) explain common device/gateway/cloud threats; (3) collect and analyze authorized logs and PCAPs; (4) inspect deliberately vulnerable firmware; (5) propose firmware, crypto, identity and update hardening; (6) triage IoT malware-like behavior; (7) build SOC detections; and (8) deliver a responsible, evidence-backed findings report.

## Required study discipline

- Every module is video-led; read the module page **before** launching a lab.
- Complete the four lessons in order. Written reflections and defensible artifacts replace quizzes.
- Use host-only VMs, IoTGoat or mock traffic; never scan external systems or intercept third-party radio signals.
- Lab hardware is **optional**, not required for the first half of the course.
- Keep a glossary, changelog, creator credits, and a portfolio of sanitized reports.
- The capstone ends in an SOC/engineering handoff rather than a quiz or automatic unlock.
