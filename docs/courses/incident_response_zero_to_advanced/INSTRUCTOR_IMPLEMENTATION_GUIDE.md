# Instructional Design and Implementation Guide

## Target learner / context

Self-directed beginners and SOC trainees. Professional/vocational learning. English source videos; captions and learner-authored summaries may be used. Approx. 12–16 weeks, 150 guided lesson topics and 30 practical module assignments. Knowledge and assessment are aligned to actual observable SOC/IR outcomes, not general ethical-hacking exploitation.

## Instructional pattern

1. **Orient (5–10 min):** Share incident question, prerequisite and evidence focus.
2. **Watch (time varies):** Direct verified YouTube video, pause to observe tool/evidence fields and decision points.
3. **Decode (20 min):** Learner explains evidence, uncertainty and escalation trigger in their own words.
4. **Practice (45–90 min):** Synthetic/authorized lab only.
5. **Document (20–40 min):** File an incident case, evidence ledger or response decision sheet.
6. **Feedback (15 min):** Check rubric, record common mistakes and remediate.

## Lesson design QA

- Every module includes at least one direct YouTube watch URL (all include two).
- Every module contains five lessons, one safe lab, free resources, knowledge checks and completion criteria.
- No video is copied or represented as owned; captions and screenshots are not republished without rights.
- Maps existing video-era terminology to current 2025 NIST Rev 3.
- Avoids production-side destructive response without an explicit authorization boundary.

## Accessibility

Provide captions/transcripts through the source player's available options; for any unavailable caption use the original text instructions as an alternative. Do not require audio-only proof. Ensure Markdown headings and descriptive URLs. Offer offline synthetic data exercises to learners without high-memory computers or paid cloud subscriptions.

## Instructor assessment workflow

Use `ASSESSMENT_AND_RUBRIC.md` to score consistent observable evidence. Record assumptions and accessibility accommodations separately. Keep any future secure answer keys in a private instructor-only location; this package intentionally includes no hidden answer key.

## External rights and editorial governance

Public YouTube accessibility is not a license to download/rehost. Link to original creator pages, verify availability before publication, and review resource access/costs periodically. Course content is an original independent draft. This package has not passed formal lecturer-in-the-loop `agentic-course-redesign` eligibility/approval/production gates; they would require the user's explicit permissions and exact targets.
