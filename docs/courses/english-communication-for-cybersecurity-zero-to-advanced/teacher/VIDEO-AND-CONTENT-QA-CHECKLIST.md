# Course QA and Publication Checklist

**Status:** Initial static checks are automated; manual pedagogical/video verification and Agentic Course Redesign approval gates remain open.

- [ ] Course owner approved scope, audience, workload and completion criteria.
- [ ] Agentic Course Redesign Gate-0A source/environment processing eligibility completed if using that protected workflow.
- [ ] Exact source manifest/access policy and production targets approved through applicable gates.
- [ ] Every module has a direct English-learning YouTube watch link and a relevant playlist link.
- [ ] Each *direct video* has been opened by a human reviewer and confirmed playable in the target geography.
- [ ] Each playlist still exists and its current episodes are appropriate to learner level.
- [ ] Captions/alternatives have been checked; module tasks can be completed accessibly.
- [ ] Video pedagogy matches each module’s **English communication** outcome (not a general cybersecurity lecture).
- [ ] No videos, screenshots, thumbnails or captions are copied without documented rights.
- [ ] All hostnames/IPs are synthetic, no user data, no real credentials, no client or internal logs.
- [ ] Technical terminology and incident examples reviewed by an SOC/IR subject expert.
- [ ] Baseline, assessments, rubric and capstone use aligned evidence and transparent criteria.
- [ ] Learner pilot (beginner + intermediate) checks time feasibility and progressive difficulty.
- [ ] Source dates, URLs and source rights checked before site publication.
- [ ] Existing course content on a target platform is not overwritten without approval.
- [ ] Publish as drafts until approvals and independent QA are complete.
