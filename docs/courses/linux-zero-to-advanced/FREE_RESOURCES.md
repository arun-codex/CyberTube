# FREE_RESOURCES — Linux reference shelf

## Official Linux docs and manuals
- Linux Foundation free *Introduction to Linux*: https://training.linuxfoundation.org/training/introduction-to-linux/
- Ubuntu Server documentation: https://documentation.ubuntu.com/server/
- Ubuntu Security documentation: https://documentation.ubuntu.com/security/
- Bash reference manual: https://www.gnu.org/software/bash/manual/
- Systemd manual: https://www.freedesktop.org/software/systemd/man/latest/
- Linux kernel documentation: https://docs.kernel.org/
- man7 Linux manual pages: https://man7.org/linux/man-pages/
- Filesystem Hierarchy Standard: https://refspecs.linuxfoundation.org/FHS_3.0/fhs/index.html

## Free Linux practice / reading
- Linux Journey: https://linuxjourney.com/
- The Linux Command Line (free PDF/text from author): https://linuxcommand.org/tlcl.php
- Linux Upskill Challenge: https://linuxupskillchallenge.org/
- OverTheWire Bandit (optional beginner Linux command puzzles): https://overthewire.org/wargames/bandit/
- MIT Missing Semester (shell & developer productivity): https://missing.csail.mit.edu/
- GNU awk manual: https://www.gnu.org/software/gawk/manual/gawk.html
- GNU grep manual: https://www.gnu.org/software/grep/manual/grep.html
- GNU tar manual: https://www.gnu.org/software/tar/manual/
- rsync documentation: https://rsync.samba.org/documentation.html
- OpenSSH manual: https://www.openssh.com/manual.html
- UFW on Ubuntu: https://ubuntu.com/server/docs/firewalls
- ShellCheck: https://www.shellcheck.net/

**Notes:** Some outside sites also advertise paid courses. Follow only the free material. Course videos and pages can change without notice.
