## Essential terminology note

Current MITRE Enterprise ATT&CK v20.1 has 15 tactics. Older videos may present 14 tactics and use the combined *Defense Evasion* taxonomy; reconcile them against the current official matrix before teaching. Do not claim ATT&CK stages are a fixed linear attack sequence.

## Quality and rights note

YouTube links are located via official MITRE/NIST-linked pages and indexed YouTube descriptions; availability, captions, regional access, playback, cost and alignment to the 2026 ATT&CK version must be rechecked before publication. Older instructional videos use older ATT&CK taxonomy.

This package links third-party videos; it does **not** include, download, remix or redistribute their audiovisual content. Lab resources labeled “free” can have optional paid features and access conditions.
