# Suggested 18-Week Study Plan — 30 Modules

Assumption: approximately 2 hours/day on 5 days/week plus some extended lab sessions. Independent video and lab durations vary; use module hour estimates as planning rather than guarantees. The original file package totals the hours stated in README.

| 04 | 06–07 | Install a Safe Splunk Learning Lab, Splunk Ingestion, Indexes and Sourcetypes |
| 05 | 08–09 | Splunk Search Interface and Basic SPL, SPL Aggregation, Eval and Time-Series Analysis |
| 06 | 10–11 | Field Extraction, Parsing and Normalization in Splunk, Enrichment, Lookups and Multi-Source Correlation |
| 07 | 12–13 | Splunk Dashboards and SOC Reporting, Splunk Alerting and Detection Rule Tuning |
| 08 | 14–15 | Investigate Credential Attacks with Splunk, DNS, Proxy and Web Security Investigation |
| 09 | 16 | Endpoint and Ransomware Investigation Using Splunk |
