# Content Studio Storyboard — Course Overview and 30 Modules

Purpose: outline original SIEM course chapters as visual/narration-ready content. The linked YouTube videos are third-party; a storyboard must not ingest, copy, revoice or reproduce them without appropriate permissions. Narration should summarize our **original course instructions**, not transcribe video content.

## Opening narration (original, ~45 seconds)

Welcome to SIEM for Cybersecurity: Zero to Advanced. You will learn how a security operations analyst collects logs, writes SPL and KQL queries, investigates alerts, and documents evidence responsibly. Start with synthetic training data, then progress to Splunk and Microsoft Sentinel. Every module provides an external video demonstration, a guided practical task, and a knowledge check. You do not need to run real attacks or buy an enterprise security license to practice the core reasoning. Confirm costs before creating any Azure resource.
